# AGENTS.md

Личный конфиг-репозиторий для клавиатуры **AJAZZ AK680 MAX** (Hall-effect) в Hyprland.
Кода для сборки/тестов здесь нет. **README.md — источник истины** о текущем состоянии
прошивки; `TASKS.md` — бэклог идей и отклонённых решений.

## Осторожно: всё мутирует живую систему
- Команды `iot_driver` требуют `sudo` и **физически подключённую клавиатуру**.
- Многие команды падают **молча** (no-op). Проверяй результат: `iot_driver keymatrix`,
  `hyprctl devices`, `hyprctl binds`.
- `iot_driver reset` спрашивает подтверждение — не дай ему повиснуть: `echo y | sudo iot_driver reset`.
- С **Windows** заливать можно без Linux и без `sudo` — тем же протоколом через HID-интерфейс 2
  (`windows/ak680_apply.py`, hidapi). См. README → «Заливка с Windows». Клавиатура при этом
  не отключается (в отличие от USB/IP через `usbipd-win`).

## Ремапы прошивки — только по ИНДЕКСАМ, не по именам
- Статическая таблица имён драйвера для правой колонки **врёт** (физика = Common68_K80X68):
  85=Home 86=Delete 87=PageUp 88=PageDown. Ремап по имени (например `remap pgup Esc`) бьёт
  в соседнюю клавишу. По индексу — применяется верно (имя в выводе будет неправильным — это нормально).
- **Index 0 — пустышка**: `remap 0 ...` молча не применяется. Физический Esc — **index 1**.
- `remap N N` ≠ no-op: числовая цель трактуется как клавиша-цифра и перезапишет клавишу.
  Меняешь прошивку — начинай с `reset`.
- Слои: Fn — `remap "Fn+T" ...`, слой 1 — `remap "L1+T" ...`.

## Прошивка RY5088 (v306)
- **Баг**: массовый `set-actuation`/`set-release` может застрять во Fn-Lock (цифры отдают
  F-клавиши). Фикс: `echo y | sudo iot_driver reset` + заново применить ремапы и активацию.
- HID-макросы (`set-macro`/`assign-macro`) — только **ASCII**. Кириллица/эмодзи не пройдут
  (важно для CAPS-задачи в TASKS.md).
- Подсветка userpic: картинка **col-major, 6 строк**, индекс клавиши `i` → пиксель
  `(col=i/6, row=i%6)`; заливать только с `--nearest`
  (`iot_driver userpic --nearest assets/userpic-tokyonight.png -s 0`).
  Колонок у платы **15** (последняя занятая позиция матрицы 89 → `89/6+1`), а ассет
  нарисован 16×6 (160×60, ×10) — лишняя 16-я колонка при заливке отбрасывается.
- **Баг (Windows/hidapi, v306)**: подряд идущие `SET_KEYMATRIX` иногда «проглатываются» —
  из пяти ремапов применились три, оставшиеся (`85`, `87`) остались заводскими.
  Лечится записью с проверкой: пишем → читаем назад → повторяем до совпадения
  (так и сделано в `set_keymatrix_verified` / `set_fn_verified` в `windows/ak680_apply.py`).
  Как ведёт себя на Linux-`iot_driver` — не проверяли; если ремапы «не встают», проверять
  `iot_driver keymatrix` и применять повторно.
- Не предлагай Mod-Tap или toggle-dots как способ «ё» — **оба отклонены** (задержка буквы
  при наборе / автоповтор). Работает: `Fn+«е»` (физический `T`).

## Периферия и OpenRGB (решение: не форкать)
- Мышь **ZELOTES C-18** (`12c9:2003`, «SOAI USB Gaming Mouse») не поддержана в OpenRGB:
  подсветку управлять через **libratbag** (готовый PR #1877, ветка `soai-c18-driver` в форке
  PadreAdamo/libratbag) или CLI `c18ctl`. Протокол раскодирован:
  https://github.com/PadreAdamo/c18_reverseengineer.
- OpenRGB **не поддерживает ни AK680 MAX, ни C-18** → форк решили **не делать**:
  контроллеры компилируются в ядро (плагинов нет), сток-прошивка RY5088 без per-LED
  стриминга (`0xE8` — только после MONSMOD-патча), т.е. OpenRGB не дал бы больше, чем
  `iot_driver`. Прецедент на будущее: Skyloong GK68HE Pro (`3151:5029`) в OpenRGB делает
  per-LED через запись UserPic. Обоснование — TASKS.md «OpenRGB — решение».

## Раскладки Hyprland
- EN/RU: бинды `code:108` (RAlt→EN) и `code:105` (RCtrl→RU) зовут
  `~/bin/layout-switch.sh 0|1`.
- Имена клавиатур evdev начинаются с `-` (`-------gaming-keyboard`) — `hyprctl switchxkblayout`
  принимает их за флаги; обязателен разделитель `--` (см. `bin/layout-switch.sh`).
- В репо — только **фрагмент** для Hyprland: `hypr/keyboard.lua` (`kb_layout = "us,ru"`,
  бинды `code:108/105`, старт Deskflow). Полный личный `hyprland.lua` здесь **специально
  не лежит** (см. приватный репозиторий) — не тащи его сюда обратно. Время правок —
  `hyprctl reload`.
